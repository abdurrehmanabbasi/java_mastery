# Phase 1: Java Basics Fundamentals

This phase focuses on the **foundations** of Java programming. Every concept builds on previous ones, so learn them in order.

## 🎯 Phase 1 Goals

By the end of this phase, you should be comfortable with:

- ✅ Java syntax and structure
- ✅ Variables and data types
- ✅ Operators and expressions
- ✅ Conditionals (if/else, switch)
- ✅ Loops (for, while)
- ✅ Arrays
- ✅ Methods and method overloading
- ✅ Recursion basics

## 📞 Common Questions

**Q: What if I don't understand a concept?**
A: Read the section in concepts.md again, run the code example, modify it, and try to break it. Understanding comes from practice.

**Q: Can I skip recursion?**
A: No. It appears in almost every interview and is used in data structures (Phase 3).

**Q: How long should Phase 1 take?**
A: 2-4 weeks, depending on your learning pace. Go slow to build strong foundations.
