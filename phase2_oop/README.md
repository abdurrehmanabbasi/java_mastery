# Phase 2: OOP and Java Core Concepts

This phase moves from procedural Java into object-oriented thinking. The goal is to learn how to model real-world problems using classes, objects, and relationships.

## 🎯 Phase 2 Goals

By the end of this phase, you should be able to:

- ✅ design classes and objects
- ✅ use constructors and `this`
- ✅ understand `static`
- ✅ apply encapsulation
- ✅ use inheritance and polymorphism
- ✅ work with abstraction and interfaces
- ✅ handle exceptions and collections
- ✅ build simple real-world Java systems

---

## 📚 Learning Flow

Follow this order carefully:

### 1. Class and Object Basics
- Theory: [concepts.md](concepts.md)
- Practice: [code](code)
- Start with `ClassesAndObjects.java`

### 2. Constructors and `this`
- Learn initialization and object creation
- Practice: `Constructors.java`, `ThisKeyword.java`

### 3. Static Members
- Understand class-level data and methods
- Practice: `StaticKeyword.java`

### 4. Encapsulation
- Hide state using private fields and public methods
- Practice: `Encapsulation.java`

### 5. Inheritance
- Reuse behavior through parent-child relationships
- Practice: `Inheritance.java`

### 6. Polymorphism
- Understand method overloading and overriding
- Practice: `Polymorphism.java`

### 7. Abstraction and Interfaces
- Learn abstract design and contracts
- Practice: `Abstraction.java`, `Interfaces.java`

### 8. Packages and Access Organization
- Understand package design and modularity
- Practice: `Packages.java`

### 9. Exception Handling
- Handle runtime problems gracefully
- Practice: `ExceptionHandling.java`

### 10. Collections Framework
- Work with lists, sets, and maps
- Practice: `Collections.java`

### 11. Scanner Input
- Build interactive programs
- Practice: `ScannerInput.java`

### 12. Mini Project Integration
- Combine multiple OOP concepts in one solution
- Practice: `MiniProject_Calculator.java`

## ✅ Learning Checklist

Before moving to Phase 3, make sure you can:

- [ ] explain class vs object
- [ ] create constructors correctly
- [ ] use `this` keyword properly
- [ ] explain `static` variables and methods
- [ ] use encapsulation to protect data
- [ ] design inheritance hierarchies
- [ ] explain method overriding
- [ ] apply polymorphism logically
- [ ] use abstract classes and interfaces
- [ ] catch and handle exceptions
- [ ] work with ArrayList / HashSet / HashMap
- [ ] build one project with multiple OOP concepts

See [LEARNING_CHECKLIST.md](LEARNING_CHECKLIST.md) for the full checklist.
