# Phase 2 Learning Checklist

Use this checklist to verify your OOP understanding before moving to Phase 3.

---

## 1. Class and Object Basics
- [ ] I can explain the difference between a class and an object
- [ ] I know how to create objects with `new`
- [ ] I understand that a class is a blueprint
- [ ] I can define attributes and methods inside a class

## 2. Constructors
- [ ] I understand what a constructor is
- [ ] I know that a constructor has the same name as the class
- [ ] I know why constructors are used to initialize objects
- [ ] I can explain constructor overloading

## 3. `this` Keyword
- [ ] I understand what `this` refers to
- [ ] I can use `this` to distinguish instance variables from parameters
- [ ] I know why `this` is important in object-oriented code

## 4. `static` Keyword
- [ ] I understand static variables and methods
- [ ] I know static members belong to the class, not to an instance
- [ ] I can explain when static methods are useful
- [ ] I know static methods cannot directly access instance variables

## 5. Encapsulation
- [ ] I understand the idea of hiding data
- [ ] I can explain why private fields are useful
- [ ] I know the purpose of getters and setters
- [ ] I can build a class with protected state and controlled access

## 6. Inheritance
- [ ] I understand the relationship between a parent class and child class
- [ ] I know what `extends` means
- [ ] I can explain the benefits of inheritance
- [ ] I can build a simple inheritance example

## 7. Polymorphism
- [ ] I understand runtime and compile-time polymorphism
- [ ] I know the difference between method overloading and overriding
- [ ] I can explain why polymorphism makes code flexible

## 8. Abstraction
- [ ] I know what abstraction means in Java
- [ ] I can explain abstract classes
- [ ] I can identify situations where abstraction helps reduce complexity

## 9. Interfaces
- [ ] I know what an interface is
- [ ] I can explain the difference between interface and abstract class
- [ ] I know that classes implement interfaces
- [ ] I understand why interfaces are useful in large systems

## 10. Packages
- [ ] I understand why packages are used
- [ ] I know they help organize code and prevent name conflicts
- [ ] I can explain package-level organization

## 11. Exception Handling
- [ ] I understand what an exception is
- [ ] I know the purpose of `try`, `catch`, and `finally`
- [ ] I can explain what `throw` and `throws` do
- [ ] I can write a simple try-catch example

## 12. Collections
- [ ] I know the purpose of the Java Collections Framework
- [ ] I can explain `List`, `Set`, and `Map`
- [ ] I know the difference between ArrayList and HashSet
- [ ] I know the difference between HashMap and HashSet
- [ ] I can use a collection in a practical program

## 13. Scanner Input
- [ ] I understand how to read user input with `Scanner`
- [ ] I know how to use `nextLine()` and `nextInt()`
- [ ] I can build an interactive Java program

## 14. Practical Project Skills
- [ ] I can build a class with state and behavior
- [ ] I can create a project using multiple classes
- [ ] I can combine constructors, methods, and collections
- [ ] I can explain the design of my project in plain English

---

## Final Readiness Check
- [ ] I can answer OOP interview questions without memorizing every word
- [ ] I can explain each concept using real examples
- [ ] I have run and tested all OOP code examples
- [ ] I have completed at least 1 OOP mini-project
- [ ] I feel ready for Phase 3: Advanced Java and Real-World Practice
