# Phase 2: OOP Interview Questions and Answers

This file contains model interview questions for OOP and Java core concepts.

## OOP basics

### 1. What is OOP?
OOP stands for Object-Oriented Programming. It organizes code into objects and classes to make programs modular and reusable.

### 2. What is a class?
A class is a blueprint for creating objects. It defines attributes and behavior.

### 3. What is an object?
An object is an instance of a class that has its own state and behavior.

### 4. What is a constructor?
A constructor is a special method used to initialize an object when it is created.

### 5. What is the use of `this` keyword?
`this` refers to the current object and helps differentiate instance variables from parameters.

## Encapsulation and static

### 6. What is encapsulation?
Encapsulation is the process of restricting access to data using private fields and public methods.

### 7. Why is encapsulation important?
It improves data security, code maintainability, and controlled access.

### 8. What is the `static` keyword?
`static` defines class-level members that belong to the class instead of a single object.

## Inheritance and polymorphism

### 9. What is inheritance?
Inheritance allows a subclass to reuse features and behavior from a parent class.

### 10. What is polymorphism?
Polymorphism allows one interface or method name to behave differently depending on the object.

### 11. What is method overriding?
Method overriding means redefining a method in a child class with the same method signature as the parent.

## Abstraction and interfaces

### 12. What is abstraction?
Abstraction hides implementation details and exposes only necessary functionality.

### 13. What is an interface in Java?
An interface defines methods that implementing classes must provide.

### 14. What is the difference between abstract class and interface?
An abstract class can have both abstract and concrete methods, while an interface mainly defines contracts.

## Exceptions and collections

### 15. What is an exception?
An exception is an event that interrupts normal program flow.

### 16. Why is exception handling important?
It prevents the program from crashing due to runtime errors and allows graceful recovery.

### 17. What is the Java Collections Framework?
It is a set of classes and interfaces like `List`, `Set`, and `Map` used to store and manage data.

### 18. What is the difference between `ArrayList` and `HashSet`?
- `ArrayList` preserves order and allows duplicates.
- `HashSet` does not preserve order and does not allow duplicates.

### 19. What is the difference between `HashMap` and `HashSet`?
- `HashMap` stores key-value pairs.
- `HashSet` stores unique values only.

## Practice questions

- What is the difference between inheritance and composition?
- Why is encapsulation preferred in real projects?
- How does a `static` method differ from an instance method?
- When should you use an interface instead of an abstract class?
- What is the purpose of `try`, `catch`, and `finally`?

## Final interview tip

For OOP interviews, focus on modeling real-world problems with classes and explaining the relationship among objects, inheritance, and behavior.
