# Phase 2 Projects

This folder contains OOP-based mini-projects to connect theory with practical Java design.

---

## Project 1: Student Management System

**Goal:** Store student information and perform academic operations.

**Use concepts:**
- classes and objects
- constructors
- encapsulation
- methods
- collections

**Features:**
- add student
- show student details
- calculate average marks
- compare marks

---

## 🔺 What to include in every project

Each project should use at least 3 core OOP ideas, such as:

- class design
- object creation
- constructors
- encapsulation
- inheritance or interface
- exception handling
- collection storage

---

## ✅ Project Completion Checklist

- [ ] The project compiles successfully
- [ ] Classes are clean and organized
- [ ] Data is protected through encapsulation
- [ ] Methods are reusable and meaningful
- [ ] Output is clear and readable
- [ ] The project uses at least 3 OOP principles
- [ ] You can explain each class and method

---

## 🧠 Best Practice

Do not just write code to get output. Design it like a real system: model the data, define behaviors, and keep responsibilities separated.
