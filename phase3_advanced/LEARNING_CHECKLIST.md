# Phase 3 Learning Checklist

Use this checklist before moving beyond advanced Java.

---

## 1. Collections
- [ ] I can explain the purpose of `List`, `Set`, and `Map`
- [ ] I can use `ArrayList`, `HashSet`, and `HashMap`
- [ ] I understand when to use each collection type
- [ ] I can explain duplicate-handling behavior in sets and lists

## 2. Generics
- [ ] I understand what generics are and why they are useful
- [ ] I can write generic classes or methods
- [ ] I can explain how generics improve type safety

## 3. File Handling
- [ ] I can write text to a file
- [ ] I can read text from a file
- [ ] I understand how to handle file-related exceptions
- [ ] I can explain why file storage is useful in applications

## 4. Exceptions
- [ ] I know the difference between checked and unchecked exceptions
- [ ] I can use `try`, `catch`, and `finally`
- [ ] I understand `throw` and `throws`
- [ ] I can write programs that fail gracefully

## 5. Lambda Expressions and Streams
- [ ] I understand the purpose of lambda expressions
- [ ] I can use a lambda with `forEach`
- [ ] I can filter and transform data using streams
- [ ] I understand how streams simplify collection processing

## 6. Multithreading
- [ ] I know what a thread is
- [ ] I understand basic thread creation
- [ ] I know that concurrency can cause issues without careful design
- [ ] I can explain why multithreading is useful in real programs

## 7. JDBC
- [ ] I understand what JDBC is
- [ ] I know the basic flow for connecting to a database
- [ ] I can explain the role of SQL in Java programs
- [ ] I know why JDBC is important in real enterprise systems

## 8. Capstone Thinking
- [ ] I can design a project using multiple advanced Java topics
- [ ] I can connect classes, collections, and storage together
- [ ] I can explain the flow of my project clearly

---

## Final Readiness Check
- [ ] I can answer advanced Java interview questions with practical examples
- [ ] I have developed at least one meaningful mini-project
- [ ] I understand not just syntax but design thinking
- [ ] I feel ready for real-world Java or backend learning
