# Phase 3 Projects

This folder contains advanced Java mini-projects and capstone-style activities designed to combine multiple topics into one real-world system.

---

## Project 1: Contact Book with File Storage

**Goal:** Store contacts and save them to a file.

**Use concepts:**
- `ArrayList` or `HashMap`
- file handling
- exception handling
- user input

**Features:**
- add contact
- update contact
- delete contact
- search contact
- save to file

---

## Project 2: Inventory Management System

**Goal:** Manage products and stock levels.

**Use concepts:**
- collections
- object-oriented design
- streams or filtering
- file handling

**Features:**
- add product
- update stock
- search item
- show total inventory value
- generate report

---

## Project 3: Student Result Dashboard

**Goal:** Track student marks and compute performance results.

**Use concepts:**
- `HashMap`
- collections
- generics
- streams

**Features:**
- add students
- input subject marks
- calculate average
- show top performers
- save results

---

## Project 4: Library Management System

**Goal:** Manage books, members, and issued books.

**Use concepts:**
- collections
- generics
- exception handling
- OOP design

**Features:**
- add books
- issue and return books
- check availability
- maintain member records

---

## Project 5: JDBC-Based Employee Database App

**Goal:** Connect a Java application to a database.

**Use concepts:**
- JDBC
- SQL queries
- exception handling
- classes and methods

**Features:**
- add employee
- update employee details
- delete employee
- list all employees

---

## 🔺 What to include in every project

Every project should combine at least 3 advanced Java ideas, such as:

- collections
- file handling or JDBC
- exception handling
- generics or streams
- clean class-based design

---

## ✅ Project Completion Checklist

- [ ] project compiles successfully
- [ ] classes are designed clearly and logically
- [ ] collections are used appropriately
- [ ] file/database storage works as expected
- [ ] exceptions are handled gracefully
- [ ] code is readable and maintainable
- [ ] you can explain the project flow in plain English

---

## 🧠 Best Practice

At this stage, do not think in isolated examples. Build systems that connect multiple advanced concepts together, because that is how real Java applications are built in the industry.
