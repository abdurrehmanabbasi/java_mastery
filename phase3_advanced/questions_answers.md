# Phase 3: Advanced Java Interview Questions and Answers

This file contains interview-focused questions for advanced Java topics.

## Collections and generics

### 1. What is the Java Collections Framework?
It is a set of interfaces and classes such as `List`, `Set`, and `Map` used to store and manipulate groups of objects.

### 2. What is the difference between `ArrayList` and `LinkedList`?
`ArrayList` is better for random access. `LinkedList` is better for frequent insertions and deletions.

### 3. What is a `HashSet`?
A `HashSet` stores unique elements and does not preserve insertion order.

### 4. What is a `HashMap`?
A `HashMap` stores data as key-value pairs and allows fast lookup by key.

### 5. What are generics?
Generics allow classes and methods to operate with type parameters, improving type safety.

## Streams and lambda expressions

### 6. What is a lambda expression?
A lambda expression is a short way to represent an anonymous function in Java.

### 7. What is a Java Stream?
A Stream is a sequence of data that supports functional-style operations like filtering and mapping.

## Exceptions and file handling

### 8. What is the purpose of exception handling?
It prevents runtime crashes and helps manage unexpected errors gracefully.

### 9. What is the difference between checked and unchecked exceptions?
Checked exceptions must be declared or handled. Unchecked exceptions are not required to be caught explicitly.

### 10. What is file handling in Java?
File handling means reading from and writing to files using classes like `FileReader`, `FileWriter`, and `BufferedReader`.

## Multithreading

### 11. What is multithreading?
Multithreading allows multiple threads to execute concurrently in a program.

### 12. Why is multithreading useful?
It improves performance and allows programs to do multiple tasks at the same time.

## JDBC and real-world Java

### 13. What is JDBC?
JDBC is the Java API used to connect Java applications to databases.

### 14. Why do companies use JDBC?
It lets Java applications store and retrieve data from relational databases.

## Practice questions

- Why is `HashMap` faster than a linear search in an array?
- What is the difference between `List` and `Set`?
- What is the benefit of generics in collection code?
- How do streams help in processing large collections?
- What is the difference between `throw` and `throws`?

## Final interview tip

For advanced Java interviews, focus on reasoning clearly about collections, error handling, and how to structure scalable solutions in real-world projects.
